# TokenPool 方案 v1（已被 v2 修订汇率与准入，见 v2 文档）2026-08-10

## 模型
每个人把用不完的模型额度存进公共池，别人按日限额免费取用；贡献被真实消耗获得积分，积分换回更大额度与优先级。存的是额度，取的是额度，积分是记账单位。

## 架构
- Nginx 统一入口 keys.YOUR-DOMAIN:18443：/ → 前端 SPA；/v1/* → 自研 Node 网关（127.0.0.1:20140）
- 前端 publishable key 直连 Supabase；网关持 service key 仅服务端
- 决策：自研轻量网关（池选择/积分/结算全定制）；MVP 仅 OpenAI 兼容端点

## 网关流程
鉴权(sha256查pool_keys) → 日配额检查 → 按剩余额度加权选贡献 → 内存解密真实key透传(含SSE) → 计量(非流式读usage;流式补include_usage解析;否则本地估算并标记) → 单事务记账(扣调用方/贡献方日额+usage_events+points_ledger) → 容错(401/403标记down换路≤2次;429冷却60s;池空503)

## 防刷
自调不计分；成功且completion>0才计分；日积分上限；新号24h冷静期；异常模式识别。

## 安全
api_key加密(pgcrypto+reveal RPC)；平台key只存sha256；限流key 60rpm/IP 120rpm/并发50；连错5次熔断；注册页合规声明。

## 分期
二期：建库+加密+健康检查+贡献录入+池水位页；三期：网关+平台key+日配额+计量；四期：积分全规则+防刷队列+管理后台。
